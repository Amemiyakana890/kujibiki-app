# 📊 抽選データ集計ページ

学園祭での抽選状況を自動で記録・集計するためのページです。

これまで手作業で行っていた「時間帯ごとの抽選回数の集計」を、抽選実行時に自動で記録することで、集計作業の負担を減らします。

## 概要

抽選を実行すると、抽選日時や当選した賞などの情報を自動的に記録します。

記録したデータは集計ページで確認でき、**時間帯別の抽選回数**や**賞別の当選数**を簡単に確認できます。

また、記録した抽選履歴はCSV形式で書き出すことができ、Excelなどの表計算ソフトで利用できます。

---

## 📈 集計ページで確認できること

### 総抽選回数

選択した日の抽選回数を確認できます。

例：

```text
1日目
総抽選回数　259回
```

### 時間帯別の抽選回数

学園祭で使用していた時間帯に合わせて、1時間ごとの抽選回数を集計します。

| 時間帯         | 抽選回数 |
| ----------- | ---: |
| 9:30〜10:30  |  23回 |
| 10:30〜11:30 |  31回 |
| 11:30〜12:30 |  45回 |
| 12:30〜13:30 |  52回 |
| 13:30〜14:30 |  48回 |
| 14:30〜15:30 |  37回 |
| 15:30〜16:30 |  23回 |

1日目・2日目を切り替えて、それぞれの抽選状況を確認できます。

集計ページは、案内ページ（`index.html`）下部の「抽選データ集計（終了後の確認用）」から開きます。お客さんが触る抽選画面（`day1.html` / `day2.html`）には、集計ページへのリンクを置いていません。

### 賞別の当選数

抽選結果を賞ごとに集計し、それぞれ何回当選したかを確認できます。

```text
A賞　○回
B賞　○回
C賞　○回
D賞　○回
```

これにより、抽選全体の状況だけでなく、賞ごとの出現状況も確認できます。

---

## 📝 抽選データの記録

抽選時には、1回ごとの抽選履歴を記録します。

記録する主な情報は以下の通りです。

```text
日付
時刻
何日目か
時間帯
当選した賞
```

例えば、

```text
2026/09/19,09:42:18,1日目,9:30〜10:30,C賞
2026/09/19,09:55:41,1日目,9:30〜10:30,D賞
2026/09/19,10:03:12,1日目,9:30〜10:30,B賞
```

のように、抽選1回ごとのデータとして保存します。

### 記録する時間帯

集計対象は学園祭の開催時間に合わせて、

* 9:30〜10:30
* 10:30〜11:30
* 11:30〜12:30
* 12:30〜13:30
* 13:30〜14:30
* 14:30〜15:30
* 15:30〜16:30

の7つの時間帯です。

9:30より前、または16:30以降に行った抽選は集計対象外としています。

そのため、開発中に動作確認のため何度も抽選を実行しても、本番用の時間帯別集計に影響しません。

対象外の抽選も記録自体は残り、集計ページに「9:30より前または16:30以降の抽選が○回記録されています」と表示されます（PCの時計がずれていた場合などに気づけるようにするためです）。時間帯は「開始を含み、終了を含まない」区間で、たとえば10:30:00ちょうどの抽選は「10:30〜11:30」に数えます。

## 📥 CSV出力

記録した抽選履歴はCSV形式で書き出すことができます。

CSVはExcelなどの表計算ソフトで開くことができるため、学園祭終了後の集計やデータの保存にも利用できます。

出力されるデータの例：

```csv
日付,時刻,日,時間帯,賞
2026/09/19,09:42:18,1日目,9:30〜10:30,C賞
2026/09/19,09:55:41,1日目,9:30〜10:30,D賞
2026/09/19,10:03:12,1日目,9:30〜10:30,B賞
```

CSVはExcelで文字化けしないよう、BOM付きUTF-8で書き出します。1日目・2日目のデータを1つのファイルにまとめて出力し、集計対象外（時間外）の抽選は含みません。

CSVでは集計結果だけではなく、**抽選1回ごとの元データ**を保存します。

そのため、Excelなどで後から別の条件で集計したり、グラフを作成したりすることもできます。

### CSV出力の用途

* 学園祭終了後のデータ集計
* 時間帯ごとの来場状況の分析
* 1日目と2日目の比較
* 賞ごとの当選状況の確認
* 抽選データのバックアップ

などに利用できます。

## 🔄 データの流れ

```text
抽選スタート
      ↓
抽選結果を決定
      ↓
抽選日時・賞などを記録
      ↓
ブラウザに抽選履歴を保存
      ↓
┌───────────────┐
│    集計ページ     │
└───────────────┘
      ↓
時間帯別・賞別に集計
      ↓
必要に応じてCSV出力
      ↓
Excelなどで利用
```

## 🧹 統計データのリセット

開発中のテストによって記録されたデータが、本番の集計に混ざらないように、統計データをリセットできる機能も用意します。

本番開始前にテストデータを削除しておくことで、学園祭当日の抽選回数を0回から正確に記録できます。

※リセットしたデータは元に戻せないため、実行時には確認を行います。1日目・2日目の記録がすべて削除されます。

※在庫のリセットや「全データを初期化する」では、抽選履歴は削除されません。

---

## 🎯 この機能の目的

昨年度は、時間帯ごとの抽選回数を手作業で数えるために、紙に正の字を書いて記録していました。

この集計ページでは、抽選を行うたびにデータを自動的に記録することで、**抽選そのものと同時に集計まで行える仕組み**にしています。

「抽選する → 記録する → 時間帯ごとに数える」という作業を自動化することで、当日の運営スタッフが手作業で集計する負担を減らし、学園祭終了後にもデータを活用できるようにしています。
