# gakusai-kuji

学園祭のブースで使う、オフライン動作のくじ引きWebアプリです。
インターネット接続不要・Windows PCでそのまま動作します。

1日目は**スクラッチ演出**、2日目は**ガチャのカットイン演出**と、日によって見た目の異なる2つのページを用意しています。スタッフが当日のページを開き、全画面表示にしてお客さんに抽選してもらう運用を想定しています。

---

## 使い方（かんたん）

1. このフォルダを丸ごと Windows PC にコピーする
2. `index.html` をダブルクリックする（案内ページが開きます）
3. 「1日目」または「2日目」を選んで進む
4. 必要に応じて「全画面表示」を押す
5. 「抽選スタート」ボタンでくじが引けます

これだけで動作します。追加インストールは不要です。

### より安定して動かしたい場合（推奨）

ブラウザによっては `index.html` を直接開く方式（`file://`）だと、
保存データ（在庫や設定）がブラウザの設定次第で不安定になることがあります。
本番当日は、同梱の `start.bat` をダブルクリックして起動する方法を推奨します。

- `start.bat` … Windows標準のPowerShell機能だけでローカルサーバーを起動します（Node.jsやPython等のインストール一切不要）
- 自動でブラウザが開き、`http://localhost:8080/index.html`（案内ページ）が表示されます
- インターネット接続は不要です（PC内で完結する通信のみ使用します）
- **開いたPowerShellのウィンドウ（青または黒の画面）が、抽選アプリのサーバー本体です。営業中は閉じないでください。** 邪魔なときは最小化（－ボタン）で構いません。終了する時（営業終了後）に、このウィンドウを閉じてください
- 万一閉じてしまっても保存データは消えません。対処は下の「[困ったとき](#困ったときトラブルシューティング)」を参照してください

## ファイル構成

```
index.html          … 案内ページ（スタッフが1日目/2日目を選ぶページ）
day1.html           … 1日目用ページ（スクラッチ演出）
day2.html           … 2日目用ページ（ガチャのカットイン演出）
style.css           … 見た目（共通）
app-core.js         … 抽選・在庫・運営画面などの共通ロジック
reveal-scratch.js   … スクラッチ演出（day1.html専用）
reveal-gacha.js     … ガチャ・カットイン演出（day2.html専用）
statistics.html     … 抽選データ集計ページ（案内ページから開く）
statistics.js       … 集計・CSV出力・統計リセット（statistics.html専用）
start.bat           … ローカルサーバー起動用（推奨）
server.ps1          … start.bat が内部で使うPowerShell製サーバー
docs/statistics.md    … 抽選データ集計ページの機能紹介
README.md           … このファイル
```

`day1.html` と `day2.html` は見た目の演出が違うだけで、**在庫・賞品設定は同じデータを共有**します（同じ `localStorage` を見ているため）。どちらのページで抽選しても、もう片方のページを開けば同じ残数が表示されます。

共通のロジック（抽選処理・運営画面・音・紙吹雪など）は `app-core.js` 1箇所にまとまっているので、修正するときは基本的にこのファイルを直せば両方のページに反映されます。演出そのもの（削る／ガチャが開く動き）だけが `reveal-scratch.js` / `reveal-gacha.js` に分かれています。

## 主な機能

- くじ引き（母数からの一様ランダム抽選、引くたびに減っていく方式）
- A賞・B賞・C賞・D賞（名称・当選数は運営画面から編集可能）
- **1日目（day1.html）**：「抽選スタート」を押すとスクラッチカードが登場。指のアイコンが自動でカードを削っていき、最後に少し溜め（ドキドキ演出）を挟んでから一気に結果が現れる（タッチ操作不要・モニター表示での運用を想定）
- **2日目（day2.html）**：カプセルが震えてパカッと割れ、賞のバナーが勢いよくスライドインするガチャのカットイン演出
- A賞（一番上の賞）が出たときは、中央に金色のA賞カードが登場し、放射状の光・きらめき・紙吹雪で祝う特別演出
- 残りの景品数を表示し、なくなった賞は結果発表のあとにふわっと消えて、自動的に表示から外れる（在庫をリセットすると設定順で戻る）
- 運営用パスワード付きの設定画面（賞品の名前・当選数・現在庫の編集、在庫リセット、直前の抽選の取り消し）
- 演出の途中で画面を閉じてしまっても、当たった結果が失われない（再読み込み後に結果を表示）
- 設定・在庫・抽選履歴のバックアップ（書き出し・読み込み）
- 抽選データの自動記録・時間帯別集計（9:30〜16:30を1時間ごとの7区間で集計）
- 賞別の当選数の集計
- 抽選履歴のCSV出力
- 統計データのリセット
  （集計ページは案内ページ（`index.html`）下部のリンクから開きます。お客さんが触る抽選画面からは開けません）
- 音のオン/オフ切り替え、全画面表示切り替え
- 全画面表示時は抽選エリアを中央に配置し、画面下部には案内ページへのリンクだけを表示（別日ページへの直接リンクはなし）

## データの保存について

設定・在庫は、**開いているブラウザの localStorage** に保存されます。`day1.html` と `day2.html` は同じキーを使うため、同じPC・同じブラウザで開く限りデータを共有します。

- 同じPC・同じブラウザで開き続ける限り、閉じても消えません
- 「ブラウザの閲覧データを消去」のような操作を行うと消えてしまいます
- データは**開いたURLごと**に別々に保存されます。`start.bat` で開く `http://localhost:8080/` と、`index.html` をダブルクリックして開く `file://…` では、別のデータになります。リハーサルも本番も、同じ開き方で統一してください
- 抽選履歴（いつ・どの賞が出たか）も同じく localStorage に保存されます。集計ページの「CSVを書き出す」でバックアップできます
- 設定・在庫・抽選履歴は、運営画面の「バックアップ」で1つのファイルに書き出せます（下の「バックアップ」を参照）
- 抽選履歴は在庫とは別に保存されているため、「在庫を満タンにリセットする」や「全データを初期化する」を押しても消えません。消すのは集計ページの「統計データをリセット」だけです

## バックアップ（書き出し・読み込み）

ブラウザのデータが消えてしまったときや、別のPC・別のURLへデータを移したいときのための機能です。

**書き出す**

1. 設定ボタン（⚙）→ パスワードを入力
2. 「バックアップ（書き出し・読み込み）」欄の「バックアップを書き出す」を押す
3. `kuji-backup_日付-時刻.json` がダウンロードされます。USBメモリなど、このPCとは別の場所にも保管してください

**読み込む**

1. 同じ欄の「バックアップを読み込む」を押し、ファイルを選ぶ
2. 確認画面で「バックアップの内容」と「現在の内容」（残り本数・抽選履歴の件数）を見比べ、よければ実行する

- バックアップに入るのは、**賞品の設定・在庫・抽選履歴**です。抽選履歴を含めるので、復元しても集計ページの記録が消えません
- **運営パスワードはファイルに含まれません。** 読み込んでも今のパスワードのままです（データが消えた後の新しい環境では、初期パスワードに戻っています）
- 読み込むと、現在の設定・在庫・抽選履歴は**すべて置き換わり、元に戻せません**。心配なときは、読み込む前に今のデータをバックアップしておいてください
- 書き出されるのは保存済みの内容です。運営画面で編集中の（「設定を保存」を押していない）内容は含まれません
- 壊れているファイルや、このアプリ以外のファイルは、何も書き込まずに理由を表示して拒否します。保存に失敗したときも、元のデータのまま変わりません
- おすすめのタイミング：本番前（設定が完成したとき）、1日目の終了後、2日目の終了後

## 押し間違い・演出中断への対応

**直前の抽選の取り消し**（押し間違えたとき）

1. 画面右上の設定ボタン（⚙）→ パスワードを入力
2. 「直前の抽選の取り消し」欄で、取り消される抽選（賞・日時）を確認して「直前の抽選を取り消す」を押す
3. 確認画面で実行すると、当たった景品が在庫に戻り、集計ページの記録も1件削除される

- 取り消せるのは**直前の1回だけ**です（もう1回さかのぼって取り消すことはできません）
- 「在庫を満タンにリセットする」を押すと取り消せなくなります
- 抽選の演出中に取り消すと、演出もその場で止まります
- その賞が設定から削除されている場合は取り消せません。また、在庫がすでに総数まで戻っている場合は、在庫を総数より増やさず、集計の記録だけを削除します

**演出の途中で画面が閉じられた場合**

抽選ボタンを押した時点で在庫は1本減るため、演出の途中で再読み込みや強制終了をすると、景品を消費したのに結果が誰にも分からなくなります。これを防ぐため、抽選した結果は自動で保存され、次に画面を開いたときに「演出の途中で画面が閉じられたため、結果を表示しています」という案内つきで結果が表示されます（表示は1回だけです）。

設定画面の「直前の抽選の取り消し」欄でも、直前の抽選の内容（賞・景品名・日時）をいつでも確認できます。

## 賞品・当選数を編集する（運営用）

`day1.html` ・ `day2.html` のどちらからでも操作できます（同じデータを編集することになります）。

1. 画面右上の設定ボタン（⚙）を押す（音量・全画面ボタンの隣）
2. パスワードを入力（初期パスワード: `kuji2026`。**運用前に必ず変更してください**）
3. 「賞品ラインナップ」で名前・総数・現在庫を編集（現在庫はその場で即座に反映されます）
4. 「設定を保存」を押す（総数の変更は現在庫の上限には反映されますが、現在庫の数自体は自動では変わりません）

パスワードは運営画面の下部からいつでも変更できます。
※このパスワードは「生徒がうっかり触って設定を壊す」のを防ぐ簡易的なものです。強固なセキュリティではない点にご注意ください。

## 抽選データを集計する

抽選するたびに、日時・何日目か・当選した賞が自動で記録されます（`day1.html` / `day2.html` のどちらで抽選しても記録されます）。

1. 案内ページ（`index.html`）下部の「抽選データ集計（終了後の確認用）」を押す
2. 「1日目」「2日目」のタブで、総抽選回数・時間帯別の抽選回数・賞別の当選数を確認する
3. 「CSVを書き出す」で、1日目・2日目すべての抽選履歴を1回ごとのデータとして保存できる（Excelでそのまま開けます）

**本番前に必ず「統計データをリセット」を押してください。** 動作確認で行ったテスト抽選が、本番の集計に混ざるのを防げます。なお、9:30より前・16:30以降の抽選は集計とCSVの対象外です（集計ページに、対象外の件数が注意として表示されます）。

詳しくは [抽選データ集計](docs/statistics.md) を参照してください。

## 開催日を切り替える

演出の切り替えは、**開くページを変えるだけ**です。案内ページ（`index.html`）から当日のページを選ぶか、スタッフが `day1.html` / `day2.html` を直接開いてください。抽選画面から別日のページへ直接移動するリンクは、誤タップ防止のため設置していません。

在庫を満タンに戻したい場合（両日で当たりの数を揃えたい場合など）は、運営画面の「在庫を満タンにリセットする」ボタンを使います。`day1.html` / `day2.html` のどちらから押しても、共有している在庫がリセットされます。通常は1日目の営業終了後、2日目が始まる前に一度押してください。

## 困ったとき（トラブルシューティング）

責任者向けの対処集です。まず、当番への引き継ぎメモとして、次の文をそのまま貼り付けて使えます。

```
【抽選くじ 当番メモ】
・黒（または青）のウィンドウは閉じない。邪魔なら最小化（－）はOK
・画面が出なくなったら、慌てず責任者へ（データはPCの中に残っています）
・押し間違えたら：⚙ → パスワード → 「直前の抽選を取り消す」
```

### 画面が出ない（「接続が拒否されました」「このサイトにアクセスできません」など）

`start.bat` で開いたPowerShellのウィンドウ（サーバー）が閉じられたか、まだ `start.bat` を実行していません。

1. `start.bat` をダブルクリックする（サーバーが起動し、ブラウザで案内ページが開きます）
2. すでにブラウザが開いているなら、`http://localhost:8080/index.html` を開き直す

- **保存データは消えません。** 設定・在庫・抽選履歴はブラウザ側に保存されています。サーバーを起動し直して、**同じURLで開けば**、続きからそのまま使えます
- サーバーが止まっても、すでに開いている抽選画面は動き続けます（抽選も設定画面も使えます）。ただし、再読み込み（F5）・タブを閉じて開き直す・別のページへの移動は、サーバーが止まっている間はできません

### PowerShellのウィンドウがどれか分からない

サーバーのウィンドウには「抽選くじアプリ サーバーを起動しました。」と表示されています。タスクバーで探してください。

### `start.bat` で「ポート 8080 が使用中か、権限が不足しています。」と出る

- すでに `start.bat` を実行済み（二重起動）のことがほとんどです。先に起動したサーバーが動いているので、新しく出たウィンドウはEnterキーで閉じて構いません。ブラウザで `http://localhost:8080/index.html` を開いてください
- 心当たりがなければ、PCを再起動してからもう一度 `start.bat` を実行してください
- 他のソフトが8080番を使っている場合は、`server.ps1` の `$port = 8080` と、`start.bat` の `8080` を、同じ別の番号に変えれば回避できます。ただし、**URLが変わるとデータは別扱いになる**ため、本番前に決めて、その後は変えないでください

### スクリプトの実行が無効になっているというエラーが出て、サーバーが起動しない

PCの管理設定でPowerShellスクリプトが禁止されている可能性があります。この場合、`index.html` をダブルクリックして開く方法（`file://`）でも動作します。ただし、保存データが `start.bat` 経由の場合とは別になり、ブラウザの設定によっては保存が不安定になることがあります。**リハーサルの段階で、本番PCで `start.bat` が動くことを必ず確認してください。**

### 設定・在庫が初期状態に戻っている／抽選履歴が空になっている

多くの場合、**前と違うURLやブラウザで開いている**ことが原因です。次はすべて別データとして扱われます。

- `http://localhost:8080/…` と `http://127.0.0.1:8080/…`
- `start.bat` 経由（`http://…`）と、`index.html` の直接オープン（`file://…`）
- 別のブラウザ（EdgeとChromeなど）、別のWindowsユーザー
- プライベートウィンドウ（InPrivate／シークレット）。閉じるとデータが消えます

前に使っていたURL・ブラウザで開き直してください。ブラウザの閲覧データを消してしまった場合は、書き出しておいたバックアップから元に戻せます（[バックアップ](#バックアップ書き出し読み込み)を参照）。

### 押し間違えた／演出の途中で画面が閉じた

[押し間違い・演出中断への対応](#押し間違い演出中断への対応) を参照してください。

### 音が出ない

画面右上のスピーカーボタン（ミュート）の状態、PCの音量・ミュート、ブラウザのタブのミュートを確認してください。また、ブラウザの仕様で、ページを開いた直後は画面を一度クリックするまで音が出ないことがあります。

### 運営用パスワードを忘れた

初期パスワードは `kuji2026` です。変更後に忘れた場合は、ブラウザで F12 キーを押し、「アプリケーション」→「ローカルストレージ」→ `kujiConfig_v1` を開くと、`adminPassword` の値で確認できます（パスワードはブラウザ内にそのまま保存されているため）。

## 動作環境

- Windows 10 / 11 の標準ブラウザ（Microsoft Edge）で動作確認を想定
- Google Chrome 等、他のモダンブラウザでも動作します
- スマホやタブレットでも一応閲覧・操作は可能ですが、本アプリはPCでの運用を想定したレイアウトです
- **大きい画面では、抽選画面が自動で拡大されます。** 画面の大きさに合わせて、画面に収まる最大の大きさ（最大3倍）まで文字・カード・演出を大きくします（例：1920×1080の全画面では約1.7倍）。設定は不要で、全画面表示でもウィンドウ表示でも働きます。画面の幅が約1130px未満の小さい画面では拡大せず、従来どおりの大きさで表示します

## カスタマイズしたい場合

- 見た目（配色・フォントなど）は `style.css` を編集してください（`day1.html` ・ `day2.html` 両方に反映されます）
- **`style.css` の大きさ（余白・文字・角丸など）は `rem` で書かれています。** 大画面での自動拡大は、`<html>` の基準の文字サイズ（`16px`）を大きくして実現しているためです。新しく大きさを足すときも `px` ではなく `rem`（16px = 1rem）で書いてください。`px` で書くと、拡大表示に追従しません（`@media` の画面幅の条件は `px` のままで構いません）
- 拡大の上限や、拡大を始める画面幅は `app-core.js` の「大画面での拡大表示」（`MAX_STAGE_SCALE` など）で調整できます。スクラッチ演出の canvas 内の寸法も同じ倍率でそろえています（`reveal-scratch.js` の `U`）
- イベントタイトルや賞品構成は、アプリ起動後に運営画面から編集する方法を推奨します
  （直接 `app-core.js` 内の `defaultConfig()` を書き換えても反映されますが、
  既にブラウザに保存データがある場合はそちらが優先されます。設定をやり直したい場合は
  運営画面の「全データを初期化する」を使ってください）
- 演出そのものを調整したい場合は、1日目なら `reveal-scratch.js`、2日目なら `reveal-gacha.js` を編集してください
