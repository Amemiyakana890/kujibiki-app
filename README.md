# gakusai-kuji

学園祭のブースで使う、オフライン動作のくじ引きWebアプリです。
インターネット接続不要で、Windows PCのブラウザから利用できます。

## 使い方

1. このフォルダをWindows PCにコピーします。
2. `start.bat`をダブルクリックします。
3. ブラウザで`http://localhost:8080/index.html`が開いたら、「抽選スタート」を押します。

`start.bat`はWindows標準のPowerShellだけでローカルサーバーを起動します。Node.jsやPythonのインストールは不要です。終了時はPowerShellのウィンドウを閉じてください。

`index.html`を直接開いても動作しますが、設定や在庫の保存がブラウザの制限を受ける場合があるため、`start.bat`の利用を推奨します。

## 主な機能

- 一様ランダムで景品を抽選し、抽選するたびに在庫を減らす
- スクラッチカードによる自動演出と当選演出
- 景品の残数表示と、在庫がなくなった景品の自動非表示
- 音のオン・オフ切り替え
- 全画面表示と、全画面終了ボタンの状態切り替え
- 運営用設定画面でイベントタイトル、景品名、総数を編集
- 現在庫を数値入力で直接調整
- 景品削除時の確認モーダル
- パスワード変更時の注意表示と確認モーダル
- 設定と在庫を初期状態へ戻す機能

## 運営用設定

1. 画面右下の歯車ボタンを押します。
2. 運営用パスワードを入力します。
3. 景品ラインナップを編集し、「設定を保存」を押します。

総数と現在庫は別々に編集できます。現在庫は0から総数まで入力でき、総数を入力中に現在庫の上限も更新されます。総数を保存しても、現在庫は自動では変わりません。

景品を削除すると確認モーダルが表示されます。削除した景品の未抽選分の在庫も一覧から削除されます。

パスワードを変更すると、次回から新しいパスワードが必要になります。パスワード変更前には確認モーダルが表示されます。

初期パスワードは`kuji2026`です。運用前に変更してください。

## データの保存

設定、在庫、抽選状態は、開いているブラウザの`localStorage`に保存されます。

- 同じPC・同じブラウザで利用する限り、ブラウザを閉じても保存されます
- ブラウザの閲覧データを削除すると、設定や在庫も消える場合があります
- 別のPCや別のブラウザとは設定・在庫を共有しません
- GitHub Pagesで複数人がアクセスしても、データは利用者ごとのブラウザに分かれます

重要な本番データは、ブラウザのデータ削除や端末故障に備えて別途記録してください。このアプリには現在、設定・在庫のエクスポート機能はありません。

## GitHub・GitHub Pagesでの公開

GitHubには次のファイルを公開できます。

```
index.html   … アプリ本体
start.bat    … Windows用のローカルサーバー起動用
server.ps1   … start.batが使うPowerShellサーバー
README.md    … この説明書
```

GitHub Pagesでは、インターネット上でデモとして表示できます。ただし、このアプリはブラウザだけで動作するため、運営用パスワードは強固な認証ではありません。ソースコードを見れば初期パスワードを確認でき、ブラウザの開発者ツールから設定を変更することもできます。

そのため、GitHub Pagesはデモや動作確認に使い、学園祭当日の本番運用は会場のPC上でローカルに行ってください。公開前に、ソースコードへ個人情報・本番用パスワード・秘密のAPIキーなどを記載していないことも確認してください。

## 動作環境

- Windows 10 / 11のMicrosoft Edgeを想定
- Google Chromeなどのモダンブラウザにも対応
- スマートフォンやタブレットでも操作できますが、PCでの運用を推奨

## カスタマイズ

- 配色やレイアウトは`index.html`内の`<style>`を編集してください
- イベントタイトルや景品構成は、起動後に運営用設定画面から変更してください
- 初期状態へ戻す場合は、運営用設定画面の「全データを初期化する」を使用してください
